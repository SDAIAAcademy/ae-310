Evaluation carries the most weight. Tuned against the base and against a larger prompted model, on the same held-out requests, with an interval and by slice.

Full marks, one line each. Decision: failure classes counted and a frozen prompted baseline. Data: a dataset card with sources, what was dropped, an overlap report and the personal-data scan. Training: a run log with both curves and the setting chosen on validation data. Evaluation: paired intervals, slices and a regression check. Serving and cost: a measured throughput under a latency target and a cost per thousand requests. The repository rubric is 60% of the course mark and the defence 20%.

Format

Ten minutes for each defence, questions included

1 · The decision · 3 min

The task, the failure classes, the frozen baseline, and what you decided: ship, ship with conditions, or do not ship.

2 · The evidence · 4 min

Run the paired comparison again, live, from the repository. Then the slices, the cost per thousand requests and the licence line.

3 · One regression · 3 min

The assessor picks one thing that got worse. Explain where it comes from and what you would do about it.

"Do not ship" is a full-marks answer when the evidence supports it. The memo is assessed on its reasoning, not on the score of the model.

The defence is of the decision memo. Keep time strictly: ten minutes in all. If the live comparison fails, the participant shows the timestamped log in the repository and says what failed.

What the assessor opens

A public repository that someone else could run

  • Decision: failure classes on the baseline, and the frozen prompt
  • Data: the tuning set or the script that builds it, the dataset card, the overlap report
  • Training: the adapter and its run log, with timestamps
  • Evaluation: outputs of the three systems, the paired comparison, the regression check
  • Serving and cost: the load-test report and the cost per thousand requests
  • The memo: one page

Before you make it public

No key, no real person's data, no data you may not publish, and a base model whose licence allows what you did. Synthetic or public data only.

The course kit is the starter: the data pipeline of Day 2, tuning.py, the evaluation of Lab 4.1 and the server of Lab 4.3 can all be reused. What is assessed is the participant's own task, data and decision. Check each repository for secrets before the session starts.
